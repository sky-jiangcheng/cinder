# 对话台：问与搜

桌面端的**首页就是一台对话台**：一个输入框，既能问出带出处的答案，也能直接搜出命中列表。搜索不再是独立顶级页——它并进了首页对话台的「搜」模式（[ADR-0038](../adr/0038-desktop-information-architecture.md) 决策 2、3）。

> 旧地址 `/search?q=…` 仍然可用：它会重定向到 `/?q=…`，对话台接管查询词并直接执行检索。老书签与外部深链不会失效，只是多跳一次。

## 两种模式

| 模式 | 做什么 | 后端 |
|------|--------|------|
| **问**（默认） | 流式给出答案 + `Sources:` 出处清单，可中断 | `AskAIWithEvidence`（同一套取证与提示装配，与 MCP `repotory_ask` 一致） |
| **搜** | 列出命中（笔记 / 待办 / 项目名） | `SearchAll`（FTS5 全文检索） |

模式由**显式开关**切换（顶栏的「问 / 搜」分段控件），不靠「回车还是点按钮」去猜。两个模式共享**同一个输入框**与**同一个项目作用域下拉**——这是它们唯一的耦合点。

未配置 AI 端点时，「问」模式走本地索引回退，并**明说「这是关键词匹配，不是答案」**；顶栏的状态胶囊也会如实显示「本地检索」而不是假装在线。

## 布局

- **空闲态**：整页居中一个大输入框 + 推荐区。
- **发起后**：输入区**常驻页面底部**，对话 / 结果流成为页面**唯一**的滚动区。

布局由「有没有对话」决定，不是一个展开动画。桌面端这一版第一次对齐两个 IDE 面板用的对话台模型（对话流是唯一滚动区、输入区常驻底部）。

## 空闲推荐：一处权威

没有对话时，推荐区把原来分散在三处的入口合成一块：

- **快捷提问**：四个可直接发起的提问（架构梳理 / 交接记录 / 最佳实践 / 待办）
- **热门项目**（top 6）：按最近个人新增行数排序；**只给名字，不给数字**——项目数、仓库数、新增行数只有仪表盘一处权威
- **热门标签**（top 12）：来自全部笔记的标签，点击即检索

## 搜模式的结果

- 命中**按项目分组**，每组带计数；项目名匹配的项单列一组
- 每条命中带一个 **「就这条追问」**：把命中标题预填进输入框并切到「问」模式——由你改完再发。这是搜与问之间唯一的耦合点（后端没有「以某条命中为上下文」的参数，所以不改后端语义）
- 查询词同步到地址栏 `?q=`，可收藏、可分享、可深链

## 与其他搜索入口的关系

| 入口 | 范围 | 特点 |
|------|------|------|
| 首页对话台「搜」模式 | 笔记 · 待办 · 项目名 | 与问答同屏，可「就这条追问」，`?q=` 可深链 |
| ⌘K / Ctrl+K 命令面板 | 笔记 · 待办 · 项目名 | 键盘快速切换，首位动作新建 handoff（见[命令面板](command-palette.md)） |
| 「知识」tab 内的搜索框 | 各自视图内筛选 | **视图内筛选**，不是全局检索——与对话台的「搜」不是同一件事 |
| 仪表盘的项目下拉 | 项目筛选 | 按项目筛今天的产出，不是检索 |
