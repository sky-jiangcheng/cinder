# ADR-0073：审核闸门降级——从「只有人能批准」到「默认人审 + 可选自动放行」

- 状态：**Accepted（2026-11-24，用户在 TODO 冲突核对后选「补 ADR 承认方向变更」，而非回滚 v2.43.0 功能）**
- 日期：2026-11-24
- 关联：[ADR-0015](0015-w3-minimal-compile-loop.md)（决策 3/6 被本篇收窄）、[ADR-0065](0065-hindsight-absorb-not-replace.md)（「人审闸门」承重边界的定义变更）、[ADR-0012](0012-semantic-search.md)（隐私授权口径不变）、`docs/product-review/2026-11-23-hindsight-experience-gap.md`（gap 2.6）、`TODO.md` 1.4（L3 自动路径禁止）

## 背景

2026-11-23 发布的 v2.43.0 实现了 AI 辅助审核：三个配置键 `wiki_review_ai` / `wiki_review_auto` / `wiki_review_timeout_hours`，其中后两个各自提供一条**自动批准**路径（AI 建议通过 + 规则通过；超时 + 规则通过）。

2026-11-24 核对 TODO 时发现，这与仓库既定的三处口径正面冲突：

| 既定口径 | 原文约束 | v2.43.0 的实际行为 |
|---|---|---|
| ADR-0015 决策 3 | 「把批准变成一个**只有人能触发**的状态迁移，而不是模型可以自我完成的动作」 | `autoApprovePage` 无人点击即可批准 |
| ADR-0015 决策 6 | 「**不接任何定时器**……编译必须由人显式按条/按项目点动」 | `wiki_review` ticker 每 5 分钟处理待审页 |
| TODO 1.4（L3 全局画像） | 「**没有任何自动路径**能填 L3」 | 超时自动批准可让页面进检索与 L3 取证 |

这不是实现走样，而是**产品方向变了**：人审从「唯一入口」变成「默认入口」。本篇承认这个变化，而不是把已发布的功能藏起来当作不存在。

## 事实（冲突核对，2026-11-24）

- 三个配置键**默认全关**：未 opt-in 时审核行为与 ADR-0015 逐字一致（人点批准、无定时器动作）。
- 两条自动路径都排在一次确定性规则否决之后：空标题 / 空 slug / 正文过短 / 占位符标记（TODO/待补充）时，无论 AI 结论或超时都不放行。
- 自动批准复用 `ApproveWikiPage`，mentions、`page_versions` 快照、磁盘投影与人工批准完全一致，**没有开第二条写路径**。
- `wiki_review` ticker 只作用于审核链；编译链仍不接定时器（ADR-0015 决策 6 对编译继续有效）。
- 人工编辑正文会清空旧 AI 结论，避免针对旧内容的自动判定残留。

## 决策

1. **闸门定义降级**：从「批准只有人能触发」改为「**人审是默认，自动放行是显式 opt-in**」。三个配置键保持默认全关；未开启时 ADR-0015 的全部约束照旧生效。
2. **自动放行只有两个收窄入口**：`wiki_review_auto=1` 且 AI 明确 approve 且硬规则通过；或 `wiki_review_timeout_hours>0` 且页面超出人工窗口且硬规则通过。硬规则否决覆盖两者，包括超时。
3. **不新开写路径**：自动批准走同一个 `ApproveWikiPage`；`review_source` 只记录 `ai` / `auto` / `timeout` / `rule`，不改内容语义、不跳过任何批准副作用。
4. **ADR-0015 原文保留 + 补注**：决策 3/6 的原文不删改，加补注横幅指向本篇；对编译链的约束（不接定时器、不进 auto_import、不进 MCP 工具面）**逐字继续有效**。
5. **ADR-0065 护城河定义同步**：「人审闸门」从承重边界改写为「**人审默认形态**是护城河，自动放行是用户主动偏离」；零模型捕获与本地单文件两条不变。
6. **TODO 1.4 收窄**：「没有任何自动路径能填 L3」改为「没有任何**默认开启的**自动路径能填 L3」；opt-in 自动放行是显式例外，sidecar 记录来源可审计。

## 代价

- **护城河稀释风险**：默认关守住了，但一旦用户开 auto/timeout，错误页就可能在无人签字下进检索——风险从「架构上不可能」变成「用户明确选择承担」。审核标注（`review_verdict/reason/source`）是事后可追溯的唯一凭据。
- **文档反转成本**：ADR-0015 的「只有人能触发」是当时的核心论证，本篇必须显式声明它被推翻，否则后来读 ADR 的人会得到错误的产品约束。
- **超时放行是产品判断不是技术结论**：「人工窗口过期」被当作默认信任，没有模型或规则在此刻重新评估正确性；这是与 Hindsight「自动 consolidate」路线的局部趋同，但刻意不带其 LLM 抽取与云形态。

## 翻转触发

- 实际库中 auto/timeout 批准的页面被人审回退（reject / 改正文）比例持续偏高 → 收回自动放行，退回 ADR-0015 原状（关掉两个配置键并在下个版本移除路径）。
- gap 2.6 的证据修订（observations 式 pending 形态 + proof count）落地后 → 自动放行的判定依据从「硬规则 + AI 建议」升级为「带证据引用与 proof count」，本篇的决策 2 需重新拍板。
